Support

Need help? Email support@thetonda.com. Please include your device model, iOS version and what you were trying to do.

Getting started

On first launch, pick the language you're learning and the language to translate into. EchoLines then downloads the speech model and translation languages for that pair. You can change both later in Settings › Learning Languages.

Subtitles don't appear

  • Make sure the speech model for the audio's language has finished downloading (Settings › Learning Languages).
  • Check that the episode's language is set correctly: open the player and tap the subtitles button.
  • Music or long silences produce no subtitles; spoken word works best.

Which languages are supported?

EchoLines supports the languages offered by Apple's on-device speech recognition and translation on your device. The list in the app shows what is available.

Importing your own audio

  • Local tab › + › Import from Files.
  • From another app, use Share › EchoLines.
  • From a computer: Local tab › + › Wi-Fi Transfer, then open the address shown on a browser on the same Wi-Fi and enter the access code.

Wi-Fi Transfer can't connect

Keep the Wi-Fi Transfer screen open, make sure the computer and the device are on the same Wi-Fi network, and allow EchoLines under Settings › Privacy & Security › Local Network.

Freeing up space

Settings › Storage shows how much space downloads and subtitles use, and lets you set a download limit, clear subtitle caches or delete downloads. Episodes you've kept are never removed automatically.
